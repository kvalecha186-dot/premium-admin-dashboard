# Starfix Admin Dashboard 🌟

A premium, state-of-the-art administration dashboard designed for managing and optimizing personal-growth mentorship programs.

[![Live Demo](https://img.shields.io/badge/Demo-Live-brightgreen?style=for-the-badge)](https://premium-admin-dashboard.vercel.app)

## 🔗 Live Link

View the live application here: **[https://premium-admin-dashboard.vercel.app](https://premium-admin-dashboard.vercel.app)**

---

## ✨ Features

- **Learners Directory**: Monitor active learners across Career & Tech, Health & Fitness, Mindset, Personal Life, and Student Life.
- **Growth Paths**: Track streaks, XP progress, and active paths.
- **Analytics & Growth Intelligence**: Dynamic visual metrics and reports.
- **Mentor Profiles & Categories**: Manage mentorship profiles and programs.
- **Modern Dark/Light Themes & Rich Micro-animations**: Premium user interface and experience.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Hosting**: [Vercel](https://vercel.com/)

## 🚀 Local Development

To run the project locally on your machine, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kvalecha186-dot/premium-admin-dashboard.git
   cd premium-admin-dashboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
